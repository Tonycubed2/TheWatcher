1. Build and install BOTH binaries above. Retain your configured INI/hotkey if desired.
2. Start Skyrim from the same MO2 Stock Game entry as usual.
3. TheWatcher.log should report helper launch and listener registration BEFORE Address Library/frame-hook installation.
4. During a pre-menu hang, press your configured key (F12 by default, F11 if configured).
5. Check SKSE\TheWatcher\independent_manual_* for capture.log, thread_snapshot.txt and, if enabled, wait_chains.txt.
6. A normal long startup must NOT create independent_emergency_* captures before DataLoaded.
7. After DataLoaded and a new heartbeat, existing gameplay/loading policies resume.
8. Exit Skyrim and confirm the helper exits. Repeat startup and save loading to check normal behavior.

LIMITATIONS
- Source package only. Windows DLL/helper compilation was performed by the maintainer and the binaries were inspected. Skyrim execution has not yet been validated.
- The early helper starts once this plugin's load function reaches settings initialization. It cannot diagnose a hang before this plugin loads.
- External manual capture needs bIndependentWatchdog=1 and a valid enabled hotkey. If the helper fails, in-game polling still starts at DataLoaded.
- Captures before DataLoaded provide external thread/module evidence; the in-game context report is unavailable until game monitoring starts.
- Missing DataLoaded/registration failure now leaves the helper available for manual capture; automatic detection remains disarmed.
